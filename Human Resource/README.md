## Application Overview
Human Resource is a basic Zoho Creator app for storing and managing HR manager records. This initial version captures each manager’s name, age, and gender through a simple web interface.

## Forms
| Form Name | Purpose | Key Lookups |
|---|---|---|
| HR Managers | Store basic HR manager details | None |

## Reports
| Report Name | Type | Source Form |
|---|---|---|
| All HR Managers | List | HR Managers |

## Pages
| Page Name | Purpose | Key Components |
|---|---|---|
| None | No dashboard required in this version | — |

## Design Decisions
- Uses required fields for complete manager records.
- Uses a controlled gender choice to keep report data consistent.
- Relies on the built-in Administrator profile for initial access.
- Provides web-only navigation and report layouts.
- Uses an HR-themed icon and professional green styling.
