## Application Overview
Student Register is a simple Zoho Creator app for recording student names, ages, and gender. It includes a searchable web directory with standard record viewing and maintenance actions.

## Forms
| Form Name | Purpose | Key Lookups |
|---|---|---|
| Students | Stores basic student details | None |

|---|---|---|
| All Students | List | Students |

## Design Decisions
- Uses required fields for complete student records.
- Uses radio buttons for consistent gender values.
- Uses Creator’s standard profiles without custom roles.
- Provides an education-themed, web-focused interface.
