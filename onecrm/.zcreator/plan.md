Create a compact Zoho Creator app component that lets users select an existing Zoho CRM Contact from a regular Creator form. The lookup will use Zoho CRM V1 Contacts, display Last Name, and will not allow creating CRM Contacts from the dropdown.

## User Profiles

Use Creator’s standard built-in profiles for this small integration feature, without introducing custom access roles.

No custom profile files. Rely on Zoho Creator’s automatically available default profiles; do not create shell profile DS files, roles, or sharing rules.
