## Application Overview
Student Registry is a compact Zoho Creator app for recording student names and ages. It provides a simple entry form and a searchable, alphabetically sorted student list.

## Forms
| Form Name | Purpose | Key Lookups |
|---|---|---|
| Students | Stores each student’s name and age | None |

## Reports
| Report Name | Type | Source Form |
|---|---|---|
| All Students | List | Students |

## Pages
| Page Name | Purpose | Key Components |
|---|---|---|
| None | The app uses standard Creator forms and reports | — |

## Design Decisions
- Student name and age are mandatory.
- The student list supports filters for both fields and sorts names alphabetically.
- Standard Creator profiles are used; no custom roles or sharing rules are needed.
- Web navigation uses an education-themed icon and a clean blue theme.
