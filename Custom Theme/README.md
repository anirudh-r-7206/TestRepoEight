## Application Overview
Student Age Registry is a lightweight Zoho Creator app for storing student names and ages. It provides a simple data-entry form, a searchable list, and a fresh green theme with friendly Nunito typography.

## Forms
| Form Name | Purpose | Key Lookups |
|---|---|---|
| Students | Store each student's name and age | None |

## Reports
| Report Name | Type | Source Form |
|---|---|---|
| All Students | List | Students |

## Pages
| Page Name | Purpose | Key Components |
|---|---|---|
| None | Not required for this compact registry | — |

## Design Decisions
- Used mandatory field properties instead of workflows.
- Kept permissions on Creator's standard default profiles.
- Added web navigation for student entry and browsing.
- Applied a green theme with Nunito typography.
- Limited the initial scope to web because mobile-specific layouts were not requested.
